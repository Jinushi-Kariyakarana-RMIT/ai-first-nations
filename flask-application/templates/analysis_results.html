About This Analysis

The system divides large imagery into tiles, checks whether mangrove vegetation is present and, when appropriate, applies the available mangrove classification model. The experimental tree counter runs independently and estimates all visible trees. Orange, Red and Yellow are retained as dataset categories; they are not described as biological species without supporting dataset documentation.
