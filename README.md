## INSTRUCTIONS
Please open this directory in Windows Powershell, or some form of Command Prompt terminal. \
\
Run the below commands (copy-paste them):

```bash
> # change the working directory to the current one
> cd C:\Users\.........\ai-first-nations\ # <--- this is the filepath to the directory
>
> # create a virtual environment to run the program
> python -m venv .venv
>
> # activate the virtual environment
> .venv\Scripts\Activate.ps1 # method for Windows Powershell
>
> # install the required libraries
> pip install -r requirements.txt
> 
> # change working directory to flask-application
> cd flask-application
>
> # run the flask app
> python app.py
```
